**Sublayer:** 0c Model configuration

**Goal.** The Human sets a team's account by the account's own name, so a line he typed before always picks the same account. Today `factory use` takes a letter, which is the account's place in the alphabetical list, so adding an account shifts the letters and the same line can pick another account.

Decided by the Human:
- 2026-11-01: he asked for this after `factory use` printed an account by its letter (the issue body).
- 2026-11-05, on INN-25: kept in Triage, to be built after release 1 ([record](https://github.com/tuannd9288/factory/issues/320#issuecomment-6651164671)).
- 2026-11-06: checked again after per-node accounts landed (#473). `factory use` still picks by letter, so it stays open ([record](https://github.com/tuannd9288/factory/issues/320#issuecomment-6680012348)).

**Acceptance.**
- `factory use <team> <account name>` sets that team's account, and the same line still picks the same account after another account is added.
- A name with no stored token is refused, names the command that adds it, and leaves the team as it was.
- Every line the factory prints for him to run names an account by its name, never by a letter.
- Open, for the Lead: whether the accounts table keeps a letter beside each name, for reading only.

**Limits.**
- An option he picks later: no work on it until he does (2026-11-06, 15:00 +07, [record](https://github.com/tuannd9288/factory/issues/375#issuecomment-6680171489)).
- Only he runs `use`, or Colly on his spoken word (INN-30). Nothing here lets an agent choose an account.
- Account names and team names stay as they are.
- #366's change to `use`, which writes the accounts file of the node a team runs on, keeps the letters, so it does not do this issue. Nor does #457.

**Prior art.**
- agent-orchestrator `9dc1c14`, `pick` in `backend/internal/service/agentaccounts/service.go:819-855`: it chooses the account it is given and refuses an unknown or signed-out one.
- piggery `67c083e`: workers run on the daemon's own login, so there is no account to name.
