**Goal.** When the agents' GitHub login runs out of API quota, the factory says so, and its own every-minute calls are not what spends it. On 2026-11-02, from 09:21 to 09:28 +07, the login hit "API rate limit already exceeded". The queue was refused for four repositories and said nothing where the Human looks, and every agent call failed. Who spent the quota was not measured.

Decided by the Human:
- 2026-11-05, on INN-25: kept in Triage, to be built after release 1 ([record](https://github.com/tuannd9288/factory/issues/331#issuecomment-6651163973)).

**Acceptance.**
- One sweep's API cost is measured, and the main consumers of the login's quota are named from that measurement.
- A sweep refused for quota says so in the events Colly follows, with the reset time when GitHub gives one.
- The queue's every-minute calls are cut to what the measurement shows is needed. Today each sweep lists up to 1,000 merged pull requests per repository. The choice comes after the measurement.

**Limits.**
- Porcelain `gh` only for agents. The measurement is the Human's step, or a script the queue already runs.
