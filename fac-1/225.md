**Sublayer:** 3a Required status checks

**Goal.** A repository whose trusted runner is not linux-x64 gets a working Claude reviewer, or a clear refusal when it is taken in. Today the reviewer's install step installs the linux-x64 package by name. On an arm64 or musl runner the reviewer is then missing, every review returns "not installed", and every merge is blocked.

Decided by the Human:
- 2026-10-29: the private repositories' self-hosted runners move to an arm64 machine when today's x64 runner is turned off, around 2026-11-10, and the kit's Claude reviewer is the planned fallback ([record](https://github.com/tuannd9288/factory/issues/225#issuecomment-6531105579)).
- 2026-11-05, on INN-25: kept in Triage, to be built after release 1 ([record](https://github.com/tuannd9288/factory/issues/225#issuecomment-6651166388)).

**Acceptance.**
- A failing test first, then one of: the step picks the package for the runner's platform, or `bin/onboard-owner` refuses a trusted runner the step cannot serve.
- Revisit when a repository on an arm64 runner is about to use the Claude reviewer, or before the runner move if any repository uses it then. zalo-gateway uses Entire, so it is not affected today.

**Limits.**
- Only repositories that use the kit's Claude reviewer are affected.
- Score: 2 × 2 = 4, so it was filed and the code left as it is.
