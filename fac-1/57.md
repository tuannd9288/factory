**Sublayer:** 2c Verification

**Goal.** Once a repository with a user interface is in the factory, a change to what a user sees comes with proof the Human can watch: a short recording, or before-and-after screenshots, of the flow it touches. He watches it from the pull request without running the app.

Decided by the Human:
- 2026-10-25: take this part of Ben Holmes' post when Kizuna's web app joins the factory, not before (the issue body).
- 2026-11-05, on INN-25: kept in Triage, to be built after release 1 ([record](https://github.com/tuannd9288/factory/issues/57#issuecomment-6651166061)).

**Acceptance.**
- In a factory repository with a user interface, a pull request that changes a screen links a recording or before-and-after screenshots of the flow it touches.
- It fails on proof of a different flow than the one changed, or on no proof for a change to a screen.
- Open: where the media lives and who makes it, the writer or the live verifier, are the Lead's to settle. The recording tool is his choice.

**Limits.**
- Waits for a repository with a user interface in the factory.
- Recordings and screenshots are never committed to the repository.
- The live verifier's verdict stays outside the gate. The gate's reviewer remains the only judge the merge waits for.
